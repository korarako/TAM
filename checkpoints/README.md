# Checkpoint provenance

TAM v0.2.0 does not include model or optimizer payloads. The immutable v0.1.0
tag preserves the historical checkpoint release. This directory records only
SHA-256 identities for the corrected runs.

The public metrics, configurations, exact scripts, and per-run hash files are
under `results/corrected`. A digest in `index.yaml` identifies an archived
research checkpoint but does not imply that the binary is distributed here.
